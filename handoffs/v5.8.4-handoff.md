## 本版改动（细则见 CHANGELOG V5.8.4）

- **模板 CSS 四处**（assets/report-template.html）：短标题 text-wrap: balance（仅无底色
  文字标题）/ 长段落 text-wrap: pretty（Firefox 未支持自动忽略）/ scroll-behavior: smooth
  收进 prefers-reduced-motion: no-preference / 首屏以下章节 content-visibility: auto +
  contain-intrinsic-size（@supports 外裹；#s1 排除；@media print 显式 visible 双保险）。
- **table-scroll 键盘可达渲染器统一注入**（render_report._fill_template 末道工序）：裸
  `<div class="table-scroll">` → 补 tabindex="0" role="region" aria-label。决议要点：
  不在 4 处生成点（charts_misc/charts_scenario/scoring + 手写约定）分散改——渲染器末道
  统一注入同源覆盖脚本生成与手写 fragment，精确字面替换天然幂等。fill-schema.md 表格节
  补一句契约说明（写作侧不变，仍写裸 div）。
- **test_17_period_track 日历敏感修复**（test_em_fetch.py）：F10 通道一并打桩返空。
  既有缺陷：v5.8.0 整期前移分支只看 F10 期次是否领先、不看字段齐不齐，而 test_17 子例 1
  只 mock 了 ts_call——三季报披露季真实 F10（或磁盘缓存）领先 mock 数据即点火变红。
  子例 2 当年以 secucode=None 规避过同源的触网问题（F7 注释），子例 1 漏网。
  前移/补齐/兜底覆盖仍由 test_18 专项承担；局部 import em_finance 遵循本文件既有惯例。

## 结转：v5.8.4 新增项

- **真实报告首轮观察**：延迟渲染在真实长报告（非 golden 测试数据）的滚动体验、锚点定位、
  打印各观察一次；contain-intrinsic-size 600px 占位与实际章高差距大时滚动条初段会偏短，
  若体感明显再调占位值。
- **审核不修登记**：px→rem 全量换算（50+ 处 px 与像素级快照耦合，要么单独立项 token 化
  要么明确不遵循，半改更糟）；overflow-wrap: break-word（table-scroll 横滚已兜底，收益低）。
- **对照示例留存**：artifacts/_layout_audit_demo/{before,after}.html 可留作下轮排版讨论
  基线，无运行时依赖。
