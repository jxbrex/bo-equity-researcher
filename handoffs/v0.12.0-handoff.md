# v0.12.0-handoff — 质量分基础分含义与四段式评分依据

## 1. 本版改动

1. **评分引擎生成解释**：九维按实际定档分支同步输出评分逻辑、真实命中标准与基础分标签；行业两轴、专项清单、现金跑道、金融回报覆盖均走各自口径。
2. **基础分术语统一**：普通 A/B/C/D 为代表分 9/7/5/2；治理为中性起点 6，资本回报中档为回报覆盖基础分 6，3B 为加权或主来源基础分，不再统称“定档起点”。
3. **报告四段解释**：摘要显示最终分、基础分及含义、实际调整与生效上限；展开区依次显示评分逻辑、定档依据、加减分、规则明细、数据缺口与补充观察。
4. **边界表达**：A 档无实际 +1 时说明为何保持 9；财务同时显示趋势轨、流动性轨与取较低档；无调整、调整抵消、档位夹取和真正生效的规则/证据上限分别表达，杠杆主驱动不再误称证据缺口。
5. **算法不变**：九维分数、权重、阈值、风险、仓位、fill 契约与 v1 路径均不变；展示层不复制评分阈值，分析师不手写另一套解释。

## 4. 结转事项（承接 v0.11.8 的长期清单）

以下为未决议题唯一权威清单；本版只销账“得分链无法解释基础分含义与定档逻辑”，其他事项不因本版完成而自动改变：

1. **固定期限评价**：20/60/120/250 交易日；未到期不得以最新收盘代替，股票与基准同口径。预测与实际偏差分开；满 10 份可兑现样本前不做显著性结论。
2. **真实名称链路**：新名称实际会话可发现、可触发，旧名称不形成重复路由；四个姊妹 skill 各自更新引用并验证。当前发现层证据不等于全链验收。
3. **真实行业整案**：互联网、券商、开发地产各至少一份完整报告；互联网 `review_only` 不得以 None 冒充通过。本版只补了互联网机械落盘差异的契约说明，未完成行业整案。
