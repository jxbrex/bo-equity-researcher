## 本版改动（细则见 CHANGELOG V5.7.0）

- 互联网：SOTP 分部倍数三级获取路径（.source 强制注明）；云/AI 分阶段定价法
  （EV/Sales→EV/EBITDA→一级市场估值×折价）；AI 资本开支回报观测链（黄灯 c 类口径）；
  开头如实标注多分部 SOTP 参数零实证。
- 医药：扩为三子类。新增器械节（集采口径；红旗沿用通用；第 3 章专项进度槽）与 CXO 节
  （订单驱动；投融资额先行 2-4 季度；倍数带待校准）；PoS 结构性上调三条件，明示沿用
  全球基准率、不编本土值。
- 金融：财险专项块（赔付率/费用率拆分、投资杠杆、PB-ROE 主锚）；银行补「中收能力」
  1C 判据行+体检表行；券商补业务结构行，PB-band 上下沿标待校准。
- 地产：土储增值率两级校准锚（已售未结隐含→同城市房价涨幅，皆缺取折让深端）；
  债务重组三方案对 NAV 影响口径表；物业股边界补关联方风险核查指引。
- 资源品（新建）：分型路由三例实证校准（紫金归因救回/神华长协煤电 DDM/赤峰成长共存对）；
  体检表加储量寿命/成本曲线分位/产量轨迹/DD&A/税负五行；估值=正常化 PE 时段匹配 +
  成本结构可比性检验 + 单位储量市值交叉；红旗沿用通用（短债豁免接 scoring.md 既有条款）。

## 研讨历程要点（防重走弯路）

- **附录增设判据三条本次成型**：通用口径系统性失灵 + 行业专属估值锚 + 实证可校准。
  防以后「行业重要所以要附录」式泛滥——白酒（失灵弱）与生猪/军工（零实证）据此被挡。
- **失灵形态有谱系**：金融/创新药/地产/互联网是重度失灵（红旗清单都要换）；资源品/
  器械/CXO 是中度失灵（红旗通用可用，只换估值+体检+Phase 0）——中度失灵不必全套
  五件套：器械/CXO 以子节形态只写补充口径，资源品以独立附录同样适配（红旗不接五件套
  模板，接入既有短债豁免条款）。
- **零实证不编参数**：七处只给结构标「待首份实证校准」（见结转挂账），这是本版与
  「拍脑袋写附录」的分界线。资源品能本轮立项而非列入候选，正因 4 次旧实证可回挖
  校准方向与口径——「有没有实证」与「实证是不是本版口径」要分开记账。
- **发布前复核制度化首跑**：ponytail-review 逮住五项（fill-schema 引用断链/豁免口径
  三方不一致/两数字漏标待校准/PoS 两处打架/README 树未同步），全部单行修复——
  新增文件类改动收尾必查 README 目录树与各索引枚举，跨文件引用目标必实地核实。
- 反对意见记录：门禁文档已 1,872 行（v5.6.1「加文档是负收益」）；附录触发式读取、
  非该行业零阅读成本，故补充成立——但每处补充必须对应一个已暴露的洞（本版五份
  合计约 +210 行，无一行 speculative 内容）。
