# v0.11.6-handoff — 九维字段契约与报告生成防复发

> 复核麦格米特、雄帝科技、华海诚科、美的集团、赢合科技五份真实会话。五份成稿均成功交付并通过
> 双视口检查；本轮按用户决定不修改旧报告，只修未来生成器、字段契约与取数纪律。

## 1. 本版改动

1. **九维字段契约补全**：`fill-schema.md` 新增 `score_inputs` 代码权威契约，逐维列字段、类型、
   枚举、必填条件和缺失后果；覆盖 12 种 `industry_profile`、通用修饰键、manual_evidence 白名单及
   完整脱敏 generic 示例。写评分输入禁止再读其他公司 fill 反推结构。
2. **增长图反幻觉**：无当前卖方共识仍画本文区间；共识只对与落盘年份一致的单年行对账，累计/其他
   年份和漏填均显式告警。历史负基数用「扭亏/转亏/减亏/增亏」文字；最新年亏损时整图豁免。
   2026-10-31 起新 fill 硬拒伪百分比，旧 fill 仅告警，保证历史重渲不被突然打断。
3. **对账与显示**：累计预测行保留 base.profit 与本文增速区间对账；小额利润、现价和空值显示不再
   丢精度或出现 `None%`。
4. **红旗口径**：E3 应收/存货与 quality_inputs 统一为完整五年窗口，现金含量仍保持近三期原口径。
5. **流程纪律**：历史 PE 带交集只是防伪底线，禁止为过校验挪 PE 带；妙想明确额度耗尽后建立未完成
   查询台账，定量/定性分别接力并披露实际通道；终止取数子代理前必须先读输出。
6. **版本**：`RENDERER_VERSION` v0.11.5 → v0.11.6；CHANGELOG 与本 handoff 同步，8 份 golden 按官方
   `GOLDEN_UPDATE=1 python scripts/test_golden.py` 路径重建。

## 2. 五份会话的关键结论

- 赢合科技在妙想 MCP 积分耗尽后确实调用了 `mx-data`，GBK 失败后经 UTF-8 补全并用于 DCF；不足是
  `mx-search` 未完成定性补证、报告未披露 skill 通道。主要是透明度和定性完整性问题，不把额度事件
  扩大解释为整份报告失效。
- 跨公司 JSON 均发生在 fill 写作期，用途是参考同分型/同版本字段结构，不是 peers 或行情缓存；未发现
  跨公司数值直接进入成稿。根因是九维字段契约不完整，本版已从源头补齐。
- 雄帝旧研冒充当前共识、华海 PE 带为过校验挪边界等只作为防复发用例，正式旧 HTML 与归档不回改。

  `_profit` 在 100.5 等边界的显示、quote 缺失时的告警措辞，均列次要后续项。
- 用户已明确「发布吧」，授权按仓库流程提交含版本号的 commit，并同步 push main、tag、GitHub release
  与部署；部署必须先预览，预览有异常则停下报告。

## 5. 结转事项（承接 v0.11.5 的 16 项）

以下保持为未决议题唯一清单；除特别注明外，本版未完成，不因字段契约和测试通过而销账：

1. **固定期限评价**：20/60/120/250 交易日；未到期不得以最新收盘代替，股票与基准同口径。
   预测与实际偏差分开；满 10 份可兑现样本前不做显著性结论。
2. **真实名称链路**：新名称实际会话可发现、可触发，旧名称不形成重复路由；四个姊妹 skill
   各自更新引用并验证。当前发现层证据不等于全链验收。
3. **真实行业整案**：互联网、券商、开发地产各至少一份完整报告；互联网 `review_only`
   不得以 None 冒充通过。本版只补了互联网机械落盘差异的契约说明，未完成行业整案。
4. **横向复核**：银行、保险各一组同业配对。68 份 canonical 仍只有 13 份可完整重算，55 份
   缺必需证据，禁止为覆盖率猜分；A/H 事实样本不替代整案。
5. **稳定边界**：标准测试、v1/v2 golden、真实 CI、旧报告回测、部署无双技能与最终独立
   整分支审查仍需持续验收。本版完成当前源码 556 项测试、golden 与独立复核，不等于历史行业整案完成。
6. **估值锚边界**：悲观/乐观 PE 带跨版移动仍未纳入证据锁，目前只锁 base；不得宣称锚纪律已全覆盖。
7. **机械输入**：`--peers` 最近同年度 `XSMLL` 接入 `quality_inputs.profile.peer_gross_margin_mean`，
   至少三家且缺值不置零；CXO 专项红旗仍需人工证据。万华同业毛利率缺失仍如实限档。
8. **数据口径**：E5 detail/aim_detail 机构名归一仍待做。Tushare 资金事实与 E5 跨进程预算沿用
   v0.11.4；申万行业估值未获可迁移接口，继续妙想。`st_bonds_payable` 有值才计入短债，不能通用拆分
   仍靠年报人工证据；其他资金接口未查询或失败保持 null。
9. **真实证据**：长电校准锚保留非阻断提示；三年 ROIC 中位数须保留景气高位反方；利润主
   来源回退仍靠人工核验。卫星情景差分的独立业务验证继续挂研究账，但不恢复三账。
10. **行业与估值参数**：互联网 SOTP、财险、券商 PB、CXO PE 与投融资滞后、资源品
    EV/EBITDA、互联网 AI 资本开支阈值继续标待校准；E2 十年窗口、3pct 尺子阈值、B6
    折现率带、±0.3 临界宽度、盈利波动 σ、成熟/停滞权重、保险/券商 85:15 按样本复核。
11. **决策方案**：盈亏比公式与薄分母、四件套按分型浮动、4.0 临界边界、A/H 结构化、周期
    soft gate 升硬条件，未经逐项拍板不动。
12. **样本触发的待决事项**：东财归属、撞车对照卡、跨期评级计数、tier 静态清单维护和
    soft gate 升拒观察，按真实样本决定，不因本版修复自动施工。
13. **ROE/PB 试算**：常数、行业阈值与是否进入正式估值须另行评审；本组没有真实亏损年
