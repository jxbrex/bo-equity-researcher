# v0.12.5-handoff — P0 证据链与估值锚闭环

## 1. 本版改动

1. **三情景 PE 证据锁**：悲观、基础、乐观任一可比 PE 带跨版移动，均须填写现有
   `valuation.pe_band_evidence`，且至少一条基本面或市场参数证据。多条移动一次列全；
   上版缺某带只跳过该带，可比带未移动仍禁止多填证据。字段结构和回滚双尺不变。
2. **E5/street 证据链**：E5 `detail/aim_detail` 按预测年与 `norm_org` 合并机构别名，
   保留最新研报原始展示名，并完整落入 quote 的 `gap_plot` 子键。A 股 street 对 quote
   明细、港股/调研 street 对 `_street` 文件，均新增前向错值与整维漏抄软告警；只展示
   机构子集不告警。gap_history 校验同步归一并保留双别名候选。
3. **peers 机械输入**：`--peers` 按目标最新年报同年度聚合 XSMLL，规范代码去重并排除
   目标股，有效值 ≥3 才写 `quality_inputs.profile.peer_gross_margin_mean`；缺值不置零、
   不回退其他年份。目标公司的 quality-v2 命令须携带同一 peers 清单，既有委派可预热缓存。
4. **审查边界修复**：重复 peer 或目标股不得伪造三家；零均值不再被当成缺失；净利率和
   扣非净利不再误配归母净利；E5 注释明确摘要 20 家、quote 明细完整。三轨算法、权重、
   阈值及既有评分分支未改，`RENDERER_VERSION` 保持 v0.12.4。

## 4. 结转事项（承接 v0.12.4，未决议题唯一权威清单）

### P1 — 补长期缺席的工具与内容约束

1. **固定期限评价工具**：20/60/120/250 交易日分桶仍未建立；未到期不得以最新收盘代替，
   股票与基准同窗口，预测偏差与实际收益分开。先建工具，再积累满 10 份可兑现样本，
   之前不做显著性结论。不是“已有工具只欠样本”。
2. **内容契约收口**：三情景 trigger 的数值阈值/时间线仍主要靠文档；核查“动笔前硬约束
   六条”中 fcst 年份、多机构单段等纯文档项及字数类软告警，不未经误报验证一律升硬拒。
   九维四要素继续要求最终 HTML 实读，机器标签合格不等于内容合格。

### P2 — 用真实环境与完整报告验收

3. **真实名称链路**：新名称实际会话可发现、可触发，旧名称不重复路由；四个姊妹 skill
   各自更新引用并验证。当前只有发现层证据，不能写成已失效，也不能写成全链通过。
4. **稳定与部署边界**：标准测试、v1/v2 golden、真实 CI、旧报告回测、部署无双技能与
   独立整分支审查持续执行；真实部署预览核销权限、文件锁和本地化输出。强杀/断电备份
   仍需人工判断，并发部署/归档未加互斥锁，不夸大为全事务安全。
5. **真实行业整案**：互联网、券商、开发地产各至少一份完整报告；互联网 `review_only`
   不得以 None 冒充通过。本版只有合成与定向真实 CLI，不替代行业整案。
6. **横向复核**：银行、保险各一组同业配对。68 份 canonical 仍只有 13 份可完整重算，
   55 份缺必需证据，禁止为覆盖率猜分；A/H 事实样本不替代整案。

### P3 — 需拍板、评审或样本积累后启动

   展示对账已修，不重开该技术项，也不等于经济校准完成。
8. **决策方案**：盈亏比公式与薄分母、四件套按分型浮动、4.0 临界边界、A/H 结构化、
   周期 soft gate 升硬条件，逐项拍板前不动。

10. **断链待决与样本后评审**：字体内嵌与 F1 效果、fill 多片段合并提效，未拍板不进
    1.0 门槛；困境反转现金转化正式清单至少 3 个独立样本后评审；因果归并更细阈值和
    重大性免扣证据真伪仍需真实样本与人工复核。
