# 医药行业附录（创新药 / 器械 / CXO）

> 创新药/Biotech 的利润表是"未来价值的脚注"——当期亏损是商业模式的阶段特征而非缺陷，
> 现金跑道与管线进度才是生存指标。**本附录用于替换通用口径**：
> 1D 盈利质量红旗清单、1D 财务体检表、估值方法、Phase 0 关键驱动识别、财报可信度替代项、fin_trend 推荐面板。
> **触发**：分型为「未盈利/管线股」且公司属于创新药/Biotech（当期亏损，或管线价值占市值主导，
> 或尚无稳定商业化利润）时，本附录优先级高于 `scoring.md` 的通用口径。
> **分型与权重**：分型「未盈利/管线股」（层占比 75:25；L1 层内权重 1A 16%、1B 12%、1C 24%、
> 1D 14%、1E 18%、1F 16%，复用 `scoring.md`「未盈利/管线」行，不新增行业权重）。
> **边界**：已稳定盈利的医药白马（商业化利润覆盖研发投入，恒瑞式）不适用本附录的红旗与
> 估值口径，走通用稳健成长框架；其财报可信度专项仍可按本附录第五节补充核查。
> **子类扩展（v5.7.0）**：第一至五节为创新药/Biotech 专属口径；医疗器械见第六节、CXO 见
> 第七节（两节各自声明触发与替换范围——失灵程度低于创新药，只替换体检表侧重与估值口径，
> 红旗清单沿用通用口径）。

## 通用原则（三条，先读）

1. **亏损是阶段，不是原罪，但烧钱速度是**。核心问题不是"亏多少"，而是"现金还能烧多久、
   烧到哪几个里程碑"。现金跑道 <18 个月的公司，估值讨论让位于生存讨论。
2. **管线是组合期权，单一依赖是最大集中度风险**。一条 III 期管线占 rNPV 70%+ 的公司，
   本质是一张二元彩票——离散度必然处于高档（阈值见 `scoring.md` 决策主轴节），仓位规则照此执行。
3. **成功率用行业基准率，不信公司口径**。管理层永远对自己的管线乐观；PoS 必须锚定
   行业 base rate（`scoring.md` 基准率节），上调需要结构性理由（条件见第三节 PoS 基准率）。

## 评分 v2 接入（创新药 / 器械 / CXO）

- **生存型 1D**：创新药管线看现金跑道，≥24 个月=A、18—23=B、12—17=C、<12=D；
  专项 `industry_checks` 存在时改用对应清单，禁止重复评分。
- **CXO 1B 两轴**：`cost_strength` 看成本效率，`pricing_strength` 看切换成本与客户黏性，
  取 strong/neutral/weak；两强=A、一强=B、均不强=C，集中度与议价权规则同总纲。
  OMB、集采中选、FOMC 等宏观或风险事件不得在 3C 冒充重估催化。
- **3B 主来源**：订单/项目缺利润权重时，唯一或组合主来源必须有人工核验证据，组合按最弱
  核心项且最高 7.9，非核心项不纳入；阶段标签不能批量冒充合约级可见度。
- **行业检查豁免**：`not_applicable` 仅用于确有依据的单项，并须在 `industry_check_evidence`
  逐项填写理由与来源；缺依据按 missing，全部不适用仍 missing；
  器械等已盈利公司按 `pharma_device` 走通用 F，不与 CXO 两轴重复。

## 一、1D 红旗清单替换（四项，替代现金含量/应收/存货/毛利率；审计意见属红灯 a 项）

| 红旗项 | 口径 | 判定 |
|--------|------|------|
| 现金跑道 | （货币资金+短期理财）÷ 年经营现金净流出 | <18 个月且无已落实融资安排 → 红旗 |
| 研发费用资本化率 | 资本化研发支出 ÷ 研发总投入 | >30% 或同比突变上行（利润美化）→ 红旗 |
| License-in 依赖度 | 外部引进管线数 ÷ 在研管线总数 | >50% 且宣传口径以"自研"为主（伪装创新能力）→ 红旗 |
| 临床数据披露 | 关键临床读出延迟 / 选择性披露终点指标 | 读出延迟 >6 个月或中途改主要终点 → 红旗 |

## 二、1D 体检表（替代 ROE 趋势/毛利率/负债率/FCF）

| 指标 | 关注点 |
|------|--------|
| 现金跑道 | 月数 = （货币资金+短期理财）÷ 月均经营净流出；与下一里程碑时点对照 |
| 研发投入绝对额与费用化率 | 投入趋势（扩张/收缩）、费用化率与同业对比 |
| 管线梯队 | I/II/III 期数量分布；青黄不接（III 期孤悬、早期断层）→ 3B 低分 |
| 已商业化产品放量斜率 | 环比增速、P/S 对照；放量不及预期 → 峰值销售假设下修 |
| BD/出海交易质量 | 首付款 ÷ 总额比例（首付款才是真钱，里程碑多为画饼）、买方资质 |
| 稀释与融资结构 | 高息可转债/折价配售频率（Biotech 隐性股东成本） |

## 三、估值方法

**rNPV 风险调整净现值（主锚）**：

```
rNPV = Σ（每管线：峰值销售 × 稳态净利率 × PoS × 折现因子）+ 净现金
```

- **PoS 基准率**（全球行业 base rate，必须标分位）：I 期→上市 ~10%、II 期 ~25%、
  III 期 ~55%、NDA/申报阶段 ~85%。**结构性上调条件**（命中方可上调一档，须写明命中
  哪条，v5.7.0）：①靶点已在人体验证（同靶点已有上市药物）；②同靶点竞品已上市且本品
  best-in-class 有临床数据；③已纳入突破性治疗程序/优先审评。基准率沿用全球行业值，
  中国创新药专属校准待实证积累——不得自行编造本土上调幅度。
- **峰值销售** = 可及患者数 × 渗透率 × 年治疗费用，必须过 `scoring.md` 基准率节检查
  （中国创新药单药峰值 >50 亿是 80+ 分位事件，>100 亿需给出全球化依据）。
- **折现**：WACC 默认 8%（与 `scoring.md` 一致），按预计上市年份折回；稳态净利率
  参考已商业化同类（创新药稳态 25-35%）。
- **交叉验证**：已商业化部分 P/S 3-8x（对照港股 18A / 美股 Biotech 同类阶段）；
  近 12 个月同靶点/同阶段 License/并购交易对价。
- **禁用**：当期 PE（负利润的符号游戏）、P/B（轻资产知识密集，账面价值无意义）、
  全程 DCF（终值假设主导一切的假精确）。

**fill 折算规则（mcap 市值口径，脚本原生支持）**：

- 三情景由关键读出成败 / PoS 假设定义：悲观 = 读出失败后的残余价值（现金底+其余管线）、
  基础 = 基准 PoS、乐观 = 读出超预期或海外大额授权。每情景算 rNPV 总值 →
  `"mcap":[低,高]`（亿元）；**禁止 profit+pe 口径（负利润）**。
- `valuation_inputs`：`pe_ttm` 填 现市值 ÷ rNPV_基础值，`pe_band` 填合理 P/rNPV 带
  （公司历史区间或可比交易校准，如 [0.8, 1.2]），`metric_label` 填 `"P/rNPV"`。
- **管线 rNPV 推导表**（每管线：峰值销售/PoS/折现因子/rNPV 贡献，含 .source 标注）
  必须完整写在 `valuation_html` 正文——只填 mcap 不写推导 = 违反反幻觉纪律。

## 四、Phase 0 关键驱动

**关键临床数据读出**（第一变量，成败二元——估"读出成功 vs 失败 → 市值 ±X%"）>
商业化放量斜率（环比/爬坡曲线）> 医保谈判/集采降价幅度 > 融资环境（18A/科创板窗口开关）。
三情景必须围绕未来 12 个月内最近的一次关键读出构建，而非拍利润区间。

## 四点五、fin_trend 推荐面板（v4.10）

| 面板 | 柱 × 线 | 数据来源 |
|------|---------|---------|
| ① 营业收入 × 研发费用率 | 柱 × 线（pct） | 营收 E3 照抄；研发费用 E3 fina_indicator `rd_exp` |
| ② 归母净利 + 扣非净利 × 净利率 | 双柱 × 线（亏损期净利率线可省） | E3 年表照抄 |
| ③ 货币资金 × 年现金消耗（现金跑道） | 柱 × 线（亿元；管线型核心面板） | E3 资产负债表+现金流量表手工算，.source 注明口径 |
| ④ 经营现金流 × 现金含量（商业化后） | 柱 × 线（阈值 0.7） | E3 年表照抄；未盈利期可省 |

管线型（未盈利）面板③优先于②④——现金跑道比利润更决定生死；growth_plot 豁免分型
在本墙同样体现：有效面板 ≥3 即可，不为凑数填失真利润线。

## 五、财报可信度替代项（M-Score 不适用：亏损期应计项与收入模型失真）

人工判断替代核查项，评级接入规则与 `forensic-accounting.md` 第 7 节一致
（C → 核心结论警示并登记风险事实与跟踪指标，不固定扣 0.5；D → 红灯回避）：

- 研发费用资本化率与同业对比（突变 = 利润美化）；
- License 收入确认口径（首付款一次性 vs 分期，是否提前确认撑收入）；
- 关联 CRO/CSO 交易定价公允性（体外资金循环风险）；
- 现金消耗 vs 融资节奏匹配（频繁折价配售 = 稀释依赖，计入 1E 而非红旗）。

审计意见仍是必查红灯项（供红灯 a 项判定，不再列于 1D 红旗清单）。

## 六、医疗器械（集采驱动型；v5.7.0，迈瑞医疗报告实证驱动立项）

**触发**：医疗器械为主业（设备/耗材/IVD）。失灵程度中等如实声明：**1D 红旗清单沿用
通用口径**（现金含量/应收/存货对器械全部适用），本节只替换体检表侧重与估值口径。
分型按扣非 CAGR 落位成长型对应层，L1 层内权重复用 `scoring.md` 矩阵，不新增行业权重。

### 体检表补充（通用指标之上加看四行）

| 指标 | 关注点 |
|------|--------|
| 集采/招标节奏 | 中标降幅 vs 放量增速（以量补价是否成立）；未中标品种的收入暴露占比 |
| 收入结构 | 设备 ÷ 耗材 ÷ 服务占比趋势；耗材与服务占比升 = 收入粘性升 |
| 海外收入占比 | 占比与增速；关税/采购限制等地缘敞口 |
| 新品获批节奏 | 注册证数量与质量（创新器械特别审查通道），不看研发投入绝对额 |

### 估值口径

PE 有效、不换锚；但集采落地前后利润中枢断层——用**集采后正常化净利**做 PE 历史时段
匹配（集采前高毛利时段不可比，匹配进来会高估合理倍数），中枢下移在估值章判词写明。

### 第 3 章专项进度槽（写进 `period_track.industry_html`）

**触发**：器械标的且最新报告期非年报（年报期第 3 章整章消失，无需填写）。内容=集采
中标/放量进度或新品获批进度；数据源=国家/省级集采公告、药监局注册批件（定性搜索），
未披露标「未披露」，不自行估算。一句判词+数据，不展开论证（论证归 4.4/5.1 章）。

## 七、CXO（订单驱动型；CRO/CDMO；v5.7.0）

**触发**：医药外包服务为主业。经济模型与药企相反——**收入是订单的滞后兑现，先行
指标是订单不是利润表**。分型按扣非 CAGR 落位成长型对应层；L1 权重复用 `scoring.md`
矩阵。红旗清单沿用通用口径，另加本节末两条行业专项核查。

### 体检表补充（通用指标之上加看四行）

| 指标 | 关注点 |
|------|--------|
| 在手订单 ÷ 年收入 | 订单覆盖倍数：覆盖厚 = 收入可见性高；趋势比绝对值重要（年报/业绩会披露，定性搜索） |
| 订单阶段结构 | 临床前/临床/商业化阶段分布；商业化订单占比升 = 粘性与单价双升 |
| 产能利用率与人员扩张 | 利用率下行 + 人员仍扩张 = 价格战前兆 |
| 大客户集中度 | 前五大客户占比突变（地缘切割/大单取消的第一信号） |

### Phase 0 关键驱动

**全球 Biotech 投融资额**（第一变量——领先订单 2-4 个季度，经验口径待首份实证校准）>
地缘政策（生物安全立法
进展）> 价格竞争烈度。三情景围绕投融资周期位置构建，而非拍利润区间。

### 估值口径

PE 有效但强周期：按订单周期位置做 PE 历史时段匹配——投融资上行期的峰值利润 PE 参照
上一轮同位置时段，不用当前利润线性外推。合理倍数带待首份 CXO 标的实证校准。

### 行业专项核查（通用四项红旗之上加查，计入 1D 扣分论据）

- 大额订单终止公告密集出现（订单取消潮）；
- 毛利率连续 2 年趋势性下行且伴随产能扩张（价格战实证）。

## 数据来源提示

- 管线/临床进度：公司公告、CDE 药物临床试验登记、ClinicalTrials.gov、年报管线图（定性搜索为主）。
- License/BD 交易：公司公告 + 新闻定性搜索（首付款/里程碑/总额必须拆列）。
- 现金跑道：em_fetch E3 现金流/资产负债表字段手工算（货币资金 ÷ 年经营净流出）。
- PoS 基准率：`scoring.md` 基准率节行业分位 + 文献定性搜索（BIO/Informa 行业成功率报告）。
- 医保谈判结果：国家医保局公示目录（降幅口径以官方披露为准）。
