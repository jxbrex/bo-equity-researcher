## 本版改动（细则见 CHANGELOG V5.7.2）

- **分字段漏标软告警**：回测模式下扫描非 `review_html` 正文（含 `cycle_html`）中的明确
  跨版信号，先剥除 class token 含 `rev` 的完整元素再扫；漏标按字段点名，不拒渲染。
- **窄触发边界**：触发词限「较上版/上一版/上版/旧报告/旧警戒线/旧版/旧锚/原假设/
  被证伪/被验证/新增重大变量/新增重大风险/清单外新增风险/本版复盘修正」；普通
  「新增产能」「3.10 及以上版本」「新旧版本口径一致」均不触发。
- **计数口径修正**：全文 `.rev` 总数改按 class token 识别，兼容 `rev num` 与单引号；
  `data-class="rev"` 不再误判为已标。
- **契约同步**：backtest.md / fill-schema.md 补「全文总数 + 跨版信号漏标」双校验；
  tasks/lessons.md 记录聚合计数、class token、触发词反例三条教训。
- **卫星化学产物回补**：正文补 6 处三类重大变化高亮（旧警戒线、护城河/利润增长/催化剂
  三项评分变化、清单外新增风险、户数规律修正），改写 3 处重复旧口径措辞后重渲；最终
  HTML 与归档 fill 均 15 处 rev class token，目标告警 0。
