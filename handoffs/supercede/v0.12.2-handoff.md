# v0.12.2-handoff — 四份复盘报告复核与生成器防复发

## 1. 本版改动

1. **九维正文三要素**：恢复「判词+量化论据+对比」逐块校验，保留卡片布局；评分/评分依据末拍独立，2026-10-31 起新 fill 缺项拒渲染，旧 fill 告警迁移。
2. **利润图与评分展示**：支持仅共识年并补空壳行、跳年、跨次年基础情景校验；数值 0 可正常解析；最新报告期亏损豁免与文档统一；治理内部正向小计不再重复展示。
3. **告警与数据口径**：正常化 ROIC 仅在落盘为 latest 时跳过不适用对账，双方 normalized 继续核对 ROIC 与三年组成；同业无方向列豁免接受正常中文；来源注内部黑话前移到 `--check`；盈利比率小数比例统一为百分比。
4. **业务构成**：新增毛利占比合计校验，补行后必须按同一毛利分母重算；特变电工由 114.4% 修正为 99.9%（103.0 亿元分母）。
5. **页面交互与可读性**：取消章节级 `content-visibility:auto`，根治深章节锚点跳偏；评分依据 `p/li` 统一 14px 与相同行高，组标题 13px。
6. **本批成品**：工业富联补 2026E 共识、统一 2027E 区间；中简科技去除错误增速图、市值假高亮与单位混乱；天赐材料只补正文；特变电工恢复官方分部并重算毛利占比。四份三轨分不变。

## 4. 结转事项（承接 v0.12.1，未决议题唯一权威清单）

1. **固定期限评价**：20/60/120/250 交易日；未到期不得以最新收盘代替，股票与基准同口径。预测与实际偏差分开；满 10 份可兑现样本前不做显著性结论。
2. **真实名称链路**：新名称实际会话可发现、可触发，旧名称不形成重复路由；四个姊妹 skill 各自更新引用并验证。当前发现层证据不等于全链验收。
3. **真实行业整案**：互联网、券商、开发地产各至少一份完整报告；互联网 `review_only` 不得以 None 冒充通过。本版未补行业整案。
