# v0.14.0-handoff — 报告质量根因整改与真实事故验收

## 1. 本版改动

1. **真实事故回归**：新增 `audit_corpus.py`，按清单隔离运行当前与原始事故 fill，支持 pass/reject、指定错误/迁移告警、相对证据路径和最终 HTML/纯正文输出；不改原件、不归档。六家事故均登记台账，金诚信原始会话未找到，未伪造完整坏样本。
2. **最终成品门禁**：`--check` 与正式渲染共用 `render_document`，在写盘前完成图表构建、模板合成、最终九维与 SVG 多重集合检查。新复盘旧图减少且无同句原因时拒渲染，旧版保留迁移告警；条件章节未实际消费的图不误报。
3. **增长链单一来源**：利润口径 v2 新增 `valuation.profit_year`。同币种、次年且最近实际归母净利为正时，3A、增长图和预期差基础利润统一派生；新报告重复手填直接拒绝，旧 fill 不覆盖。隔年、非正分母、缺年表、市值口径和跨币种不硬算；同币种隔年合并行只核对累计区间。
4. **真实终审修正**：益丰图注“本文中枢”统一改为“区间中点”；中免修正版按官方 A 股年报统一 35.86 亿及人民币累计区间 17.1%-67.3%，港元估值与三轨分不变。正式历史报告未批量改写。

## 3. 本轮裁决与边界

- 用户选择当前 main 工作区直接修改，不创建 worktree；不提交、不发布、不部署。
- 仅同币种、次年且正实际利润自动派生；隔年/累计保留原研究语义，不用卖方预期补洞。
- 旧日期坏样本命中指定迁移告警即算拦截，不把旧 fill 倒改为硬拒。被更早错误遮蔽的样本另建隔离副本，只修前置错误并保留原始 bad 目录。
- 派生增速统一一位小数，避免 16.8057% 浮点噪音；真实益丰派生与当前成品因此保持一致。
- 原中免当前版未被独立终审放行；验收改用仅修正已有官方口径的隔离版本，不重做股票研究。
- 金诚信只登记复核证据和当前整案通过；完整原始坏样本仍待原会话恢复。
- 留档 Minor：`compute_scores` 的 v1 文档字符串失效、派生/非派生对象身份差异缺注释、`check_fill` 顶层键计数含内部键。均不影响本次运行与验收，未借终审扩大范围。
