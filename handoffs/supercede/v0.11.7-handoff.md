# v0.11.7-handoff — 热核审计评分、取数与校验边界修复

## 1. 本版改动

1. **估值边界**：非正 `pe_ttm` 不再进入“越低越便宜”映射，避免亏损公司获得合理倍数高分。
2. **取数硬停**：东财月线缩放校准、杜邦、港股年表、无风险利率四处 429 恢复穿透；无风险利率限流失败不写按日缓存。
3. **历史底稿**：`score_dist` 同日 HTML 只绑定同报告目录唯一 fill；多份 HTML 时不再跨目录使用全局唯一 fill，归属不明标冲突。
4. **重述报表**：财务机械输入保留 `report_type` 1/4，由既有最新公告逻辑选择调整行。
5. **数值与图表**：共享 `_num` 对 NaN/Infinity 及溢出数字字符串返回 None；散点图 points 与 bands 共用该边界。
6. **校验架构**：公共工具移至 `validate_common.py`，五个域模块解除循环导入；`validate.py` 保留实际调度所需导入。
7. **版本**：`RENDERER_VERSION` v0.11.6 → v0.11.7；README 当前发布号同步，修复版本漂移。

## 2. 独立审查与执行裁决

- 独立整分支审查发现：多 HTML 仅一份 fill 时仍可能跨目录错绑、散点图 bands 绕过有限数守卫、超长数字字符串可返回 Infinity。三项均补反例并修复。
- 原计划“删除约 68 行再导出层”被修正：其中大部分是 `_validate_content_impl` 的实际调度依赖，不能为追求行数删除；只迁移公共工具并清理未用名字。
- 非 429 的无风险利率失败缓存、指定四条之外的东财异常、不同目录同名 HTML 首选仲裁、两个独立 `_num` 均不纳入本轮扩修。
- 延期次要项：多 HTML 且无首选索引时，`fill_conflict` 可能被仲裁写成 `duplicate`；不会进入评分，仅冲突原因标签不准确。

## 3. 验证证据

- 新增 14 项反例均先 RED 后 GREEN；最终 `PYTHONDONTWRITEBYTECODE=1 python -m pytest scripts/ -q -p no:cacheprovider` → **570 passed**。
- 13 项 golden 全部通过且未重建；五个校验域模块均可在全新 Python 进程独立导入。
- `git diff --check` 通过；无临时报告、缓存或测试产物进入仓库。
- 用户确认按 v0.11.7 发布，授权提交、push main、tag、GitHub Release 与部署；部署必须先预览，预览有异常则停下报告。

## 4. 发布边界

- 本版只完成热核审计第 1–6 项及独立审查发现的同边界缺口，不处理第 7–15 项（第 15 项版本漂移除外）。
- 不改变评分阈值、公开 fill 契约或正常输入的渲染结果；不执行真实网络取数。
- 未合入前所有改动保留在 main 工作区；无独立功能分支，发布按仓库既定版本流程执行。

## 5. 结转事项（承接 v0.11.6 的 16 项并追加本轮清单）

以下为未决议题唯一权威清单；除特别注明外，本版未完成，不因测试通过而销账：

1. **固定期限评价**：20/60/120/250 交易日；未到期不得以最新收盘代替，股票与基准同口径。
   预测与实际偏差分开；满 10 份可兑现样本前不做显著性结论。
2. **真实名称链路**：新名称实际会话可发现、可触发，旧名称不形成重复路由；四个姊妹 skill
   各自更新引用并验证。当前发现层证据不等于全链验收。
3. **真实行业整案**：互联网、券商、开发地产各至少一份完整报告；互联网 `review_only`
   不得以 None 冒充通过。本版只补了互联网机械落盘差异的契约说明，未完成行业整案。
4. **横向复核**：银行、保险各一组同业配对。68 份 canonical 仍只有 13 份可完整重算，55 份
   缺必需证据，禁止为覆盖率猜分；A/H 事实样本不替代整案。
5. **稳定边界**：标准测试、v1/v2 golden、真实 CI、旧报告回测、部署无双技能与最终独立
   整分支审查仍需持续验收。本版完成当前源码 570 项测试、golden 与独立复核，不等于历史行业整案完成。
6. **估值锚边界**：悲观/乐观 PE 带跨版移动仍未纳入证据锁，目前只锁 base；不得宣称锚纪律已全覆盖。
7. **机械输入**：`--peers` 最近同年度 `XSMLL` 接入 `quality_inputs.profile.peer_gross_margin_mean`，
   至少三家且缺值不置零；CXO 专项红旗仍需人工证据。万华同业毛利率缺失仍如实限档。
8. **数据口径**：E5 detail/aim_detail 机构名归一仍待做。Tushare 资金事实与 E5 跨进程预算沿用
   v0.11.4；申万行业估值未获可迁移接口，继续妙想。`st_bonds_payable` 有值才计入短债，不能通用拆分
   仍靠年报人工证据；其他资金接口未查询或失败保持 null。

   来源回退仍靠人工核验。卫星情景差分的独立业务验证继续挂研究账，但不恢复三账。
