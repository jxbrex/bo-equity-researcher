# v0.9.1-handoff — 估值与文档一致性、v2 主快照、审计可见性与 CI

> 本版只做已证实的一致性修复和工程验收，不改变历史仓位结论。时机解耦、周期三账、固定期限评价及 1.0 整案验收分别见第 2、6 节，不得借本版全绿提前宣称完成。

## 1. 已实现与验证

- **期限与估值锚**：新报告（2026-10-26 起）三情景必须共用明确期限，区间期限和不同期限拒渲染；旧报告仅告警。`pe_band_evidence` 允许基本面或市场参数，价格/卖方观点仍禁用。市场参数只支撑系统性估值调整，不冒充个股相对重估证据。
- **分型与章节**：F 式总表与代码档位对齐；成长型中速层 DCF 强制、高速层按 FCF 门槛；成熟/停滞补入 DCF 软告警。周期/成长/稳定价值/成熟·停滞/困境反转的第 11 章新报必写、旧报告仅告警，未盈利·管线跳过。
- **数据与兼容**：最低 Python 改为 3.9+。筹码平均成本与「盈利比率」经 2026-10-26 实测均可返回，文档改逐项单查并保留别名；旧“死信号”改记为查询路由与字段映射问题。README、data-collection 与 em_fetch 的 peer 示例统一为 ≥3 家。
- **v2 主快照**：新增 `golden/v2_fill.html`，覆盖九维得分链、统一风险登记和 `data-quality-version=2`；变异自证可击穿，golden 总数 12→13。
- **审计可见性**：`validate_content` 返回软告警，最终 HTML 新增 `AUDIT_HTML` 口径与复核限制区；硬拒规则与 stderr 文案不变。8 份快照有意重建，剥离审计块后与旧版逐字一致。
- **CI**：新增 `.github/workflows/test.yml`，覆盖 Ubuntu/Windows × Python 3.9/3.12 的完整离线测试。
- **验证**：全套 **473 passed**；golden 13 项通过。`RENDERER_VERSION` v0.9.0 → v0.9.1。
