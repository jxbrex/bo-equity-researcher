# v5.7.3-handoff — 图表来源注去内部黑话 + 最终 HTML 硬门禁（卫星化学伪来源实证）

> 缘起：卫星化学 002648 复盘报告用户实读发现大量伪「数据来源」注释，如「脚本按
> period_track 字段生成，数据照抄 em_fetch period_track 照抄行」「脚本按 segments 字段
> 生成，数据来自 em_fetch E6/年报」「脚本按 growth_plot 字段生成」。逐层核对后确认：
> 不是模型偶发写错，而是脚本图注硬编码内部字段/工具名；`validate_content` 在图表注入前
> 执行，最终 HTML 层无门禁；golden 快照反向固化坏文案。历史修复只覆盖 9 章两图，未横扫
> 同类。

## 本版改动（细则见 CHANGELOG V5.7.3）

- **21 处来源注统一改写**：新增 `charts_base._chart_source(title, source, note)`，脚本图注
  统一为 `source chart-source`，来源写公司定期报告/公开行情/券商研报/本报告计算/本文估算等
  读者可核验出处；覆盖 period/l1/misc/gap/score/cycle/scenario 图注与 `PERIOD_SUB`。
- **来源 helper 自检**：标题/来源/口径说明命中内部黑话即拒；来源必须是非空字符串，
  空壳、None、非字符串均拒。
- **最终 HTML 硬门禁**：`render_report._check_source_spans` 在 `_fill_template` 后、
  `_write_html` 前执行；所有 `.source` 禁内部实现名，`.chart-source` 必须含非空
  「数据来源：」。门禁覆盖 class 大小写、单双引号、嵌套 span、HTML 实体与禁词大小写变体。
- **测试**：新增最终 HTML 正向全扫、手写黑话拒渲染、helper 三向自检、六种逃逸负向与
  Shareholders 不误伤；测试侧禁词表独立硬编码，避免与实现同源退化假绿。
- **文档与教训**：SKILL.md / fill-schema.md 明确「字段名/抓取脚本名/E1-E6 编号不是来源」；
  tasks/lessons.md 记录最终 HTML 层验收与同类硬编码一次横扫规则。
- **golden**：7 份快照有意重建；剥离来源注与 section-meta 后与旧版逐字节一致，未夹带
  图形结构、数值、布局或判词变化。

## ponytail/独立复核与修正

- 首轮复核确认主方案成立，但实证出三个 Important：空来源壳可绕过、class 只认小写双引号、
  嵌套 span/实体/大小写缺测试。
- 修复轮逐项先红后绿：helper 空来源拒、最终门禁支持单双引号与大小写、文本 unescape 后
  扫黑话、深度感知配对嵌套 span、测试侧独立抽取器防假绿。
- 二轮复核补堵 `_chart_source(title, None)` 输出「数据来源：None」边角。
- ponytail-review 第三轮实证出 4 项边界并全部核销：无引号 `class=source`、未闭合 `.source`、
  禁词表逐词拒渲染覆盖、HTML 注释误扫；门禁现为八类边界负向 + 22 词逐项拒渲染。
- 最终复核 Ready，无 Critical/Important 遗留。

- **来源注门禁首轮观察**：禁词表大小写不敏感且 fail-closed，理论上会拦「比亚迪 e5 车型」
  这类正常文本；暂不为假想场景放宽，出现真实误报样本再收窄边界。

  更新某份存量报告时，用对应 fill 重新渲染并复核视觉/来源注。
